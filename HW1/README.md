# Bass Model – Innovation Diffusion Analysis

## Project Overview

This project applies the Bass Diffusion Model to estimate the adoption of AST SpaceMobile's BlueBird technology.

The historical look-alike innovation used in the analysis is mobile cellular subscriptions.

## Selected Innovation

AST SpaceMobile BlueBird

TIME Best Inventions 2025:
https://time.com/collections/best-inventions-2025/7318228/ast-spacemobile-bluebird/

## Historical Data

The historical data consists of global mobile cellular subscriptions from the World Bank, sourced from the International Telecommunication Union (ITU).

Data source:
https://data.worldbank.org/indicator/IT.CEL.SETS

## Methods

The Bass model parameters p, q, and M are estimated using nonlinear curve fitting.

The estimated parameters are then used to forecast the diffusion of AST SpaceMobile BlueBird.

## Scope

The analysis uses a global scope.

## Main Forecast

The model estimates approximately:

- 30.4 million cumulative adopters by 2030
- 130.0 million by 2035
- 439.9 million by 2040
